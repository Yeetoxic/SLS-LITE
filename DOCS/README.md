# SLS-LITE Documentation

This directory separates public operator guidance from development records and
local test-environment procedures.

## Operators

| Document | Purpose |
| --- | --- |
| [Getting Started](Getting_Started.md) | Installation, first startup, updates, backups, and removal. |
| [Configuration](Configuration.md) | Complete host configuration reference and restart behavior. |
| [Blueprints](Blueprints.md) | Blueprint schema, registries, limits, persistence, properties, and annotations. |
| [Commands](Commands.md) | Implemented command forms, selectors, force options, and permissions. |
| [Operations](Operations.md) | Lifecycle, logs, troubleshooting, recovery, and constrained-host guidance. |
| [Migration](Migration.md) | Historical SLS, modern SLS subset, and earlier SLS-LITE snapshot migration. |
| [Data Layout](Data_Layout.md) | Generated directories, ownership metadata, and backup boundaries. |
| [Software Installation](Software_Installation.md) | Paper, vanilla, and manual software profiles and caches. |
| [SLS-Limbo](SLS_Limbo.md) | Virtual fallback behavior, routing, recovery, and limits. |
| [Resource Packs](Resource_Packs.md) | Current multiplayer resource-pack support and limitations. |

The commented files generated by SLS-LITE remain the canonical examples for
their schema:

- `src/main/resources/config.yml`
- `src/main/resources/template.yml`
- `src/main/resources/paper-software.yml`
- `src/main/resources/vanilla-software.yml`

## Compatibility

| Document | Purpose |
| --- | --- |
| [Compatibility](Compatibility.md) | Current feature scope and local adaptations. |
| [SLS v0.2.0 Compatibility Matrix](SLS_v0.2.0_Compatibility.md) | Pinned field comparison, scope decisions, and integration evidence. |
| [SLS Command Compatibility](SLS_Command_Compatibility.md) | Pinned vSLS command contract and remaining command work. |
| [Protocol Compatibility](Protocol_Compatibility.md) | Tested SLS-Limbo and ViaVersion protocol paths. |

Compatibility claims are versioned observations, not promises that every
modern SLS file is accepted. The pinned matrix records the supported subset,
intentional differences, and reproducible evidence.
