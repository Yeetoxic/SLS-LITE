# Current Release

The current candidate is **SLS-LITE 0.1.0-rc.2.1**.

Read the canonical [release notes](https://github.com/Yeetoxic/SLS-LITE/blob/main/RELEASE_NOTES.md),
[installation and upgrade guide](https://github.com/Yeetoxic/SLS-LITE/blob/main/DOCS/Getting_Started.md),
and [compatibility matrix](https://github.com/Yeetoxic/SLS-LITE/blob/main/DOCS/Compatibility.md).

The repository documentation and this Wiki describe the latest supported
release only. For an older installation, back up its complete data directory,
read the current migration guidance, and upgrade rather than relying on an old
manual as the active support contract.
